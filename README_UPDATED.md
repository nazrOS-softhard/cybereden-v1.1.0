# 🎮 Игровая механика

Внутри CyberEden используется система сигнатур активности пользователя.

## ◉ КРУГ

```txt
○
```

### Социальная / медиа активность

- стримы
- публикации
- комментарии
- участие в событиях
- коммуникация
- медиа

```txt
1 → низкая активность
9 → максимальная активность
```

Пример:

```txt
○7
```

---

## ◉ ТРЕУГОЛЬНИК

```txt
△
```

### Инженерная / разработческая активность

- код
- frontend
- backend
- HUD
- Unreal Engine
- архитектура
- системные модули

```txt
1 → начинающий
9 → core engineer
```

Пример:

```txt
△9
```

---

## ◉ КВАДРАТ

```txt
□
```

### Инфраструктура / производство

- серверы
- деплои
- устройства
- growthN
- pipeline
- производство контента

```txt
1 → локальный уровень
9 → инфраструктурное ядро
```

Пример:

```txt
□8
```

---

## Комбинированный профиль

```txt
△8 ○6 □4
```
