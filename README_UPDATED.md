# 🎮 Игровая механика

Внутри CyberEden используется система сигнатур активности пользователя.

## ◉ КРУГ

```txt
○
```

### Социальная / медиа активность

- стримы
- публикации
- комментарии
- участие в событиях
- коммуникация
- медиа

```txt
1 → низкая активность
9 → максимальная активность
```

Пример:

```txt
○7
```

---

## ◉ ТРЕУГОЛЬНИК

```txt
△
```

### Инженерная / разработческая активность

- код
- frontend
- backend
- HUD
- Unreal Engine
- архитектура
- системные модули

```txt
1 → начинающий
9 → core engineer
```

Пример:

```txt
△9
```

---

## ◉ КВАДРАТ

```txt
□
```

### Инфраструктура / производство

- серверы
- деплои
- устройства
- growthN
- pipeline
- производство контента

```txt
1 → локальный уровень
9 → инфраструктурное ядро
```

Пример:

```txt
□8
```

---

```txt
△8 ○6 □4
```

# 📂 Система файлов и XP

## Поддерживаемые категории

- **Цифровые артефакты** — HUD-интерфейсы, иконки, логотипы, шрифты, визуальные системы
- **Системные модули** — модули для авторизации, интеграции с Twitch, плагины для дашборда
- **Объёмные модели** — 3D-модели, сцены, ассеты для игровых движков
- **Медиа модули** — звуки, музыка, видео, анимации, визуальные эффекты
- **Цифровые протоколы** — документация, схемы, спецификации, API-интерфейсы
- **Цифровые сущности** — цифровые личности, аватары, профили, ID-системы
- **Стрим-файлы КиберэдэН** — файлы для стриминга, трансляций, прямых эфиров
- **Модели игровых движков** — ассеты для Unreal Engine, Unity, Godot
- **Файлы разработчиков игр** — GDD, баланс-таблицы, дизайн-документы
- **ИИ-боты** — Python-скрипты, Telegram-боты, NPC-логика, AI-модели
- **Пространства и уровни** — игровые уровни, карты, локации, виртуальные пространства
- **Кинематографические файлы** — видео, сцены, рендеры для кино, трейлеров
---

## Статусы файлов (Badge)

- **LIVE** — 🔴 Используется в текущем стриме
- **NEW** — 🆕 Новый файл, только что загруженный
- **CORE** — ⚙️ Ключевой файл для системы
- **SYSTEM** — 🖥️ Системный файл для инфраструктуры
- **FEATURED** — 🌟 Рекомендованный файл
- **RESTRICTED** — 🔒 Доступ только для определённых пользователей
- **EXPERIMENTAL** — 🧪 Тестовый файл, может содержать ошибки
- **ALPHA** — 🅰️ Начальная версия файла
- **BETA** — 🅱️ Тестовая версия файла
- **CLASSIFIED** — 🛡️ Файл с грифом «секретно»

## Система редкости

```txt
обычный      → белый
редкий       → синий
эпический    → фиолетовый
легендарный  → красный
системный    → neon nazrOS
```
